# Hook Engine

Prospect in, researched and reviewed outreach draft out. Nothing is ever sent automatically.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py` (put `GEMINI_API_KEY=...` in a `.env` file next to app.py).

Deploy on Streamlit Community Cloud: main file `app.py`; add `GEMINI_API_KEY` and `ACCESS_CODE` under Settings > Secrets.
